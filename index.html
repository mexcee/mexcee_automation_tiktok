System Automatize TikTok

Manage and publish social media content from one place.

What is this?

System Automatize TikTok is a personal, non-commercial project. It uses a self-hosted instance of Postiz, an open-source social media scheduling tool, running on the administrator's own computer.

It lets the administrator prepare videos and captions, then publish or schedule them on their own social media accounts, including TikTok and YouTube.

How TikTok is used

  • The account owner signs in with TikTok (Login Kit) and explicitly authorizes the application.
  • Videos and captions are sent to TikTok through the Content Posting API only when the account owner requests a publication.
  • Access can be revoked at any time from the TikTok app settings.
